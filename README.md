### General description of the repository

This repository contains the source code used to produce the results presented in the research article:  
*"Unequal exchange of labour and global justice: principles for a fair international distribution of work"*.

The source code is written with the [R](https://cran.r-project.org/) programming language.

The file `_targets.R` contains the pipeline to generate the results.

The folder `./data/` contains some of the raw data used in the pipeline, including external (`./external`) and own data (`./internal`).

The folder `./R/` contains the .R files defining the functions called by the pipeline.

The .R files are organized as following:

- `1_wrangling.R`: import and wrangle local files 
- `2_preprocessing.R`: preprocess MRIO objects from the GLORIA dataset
- `3_processing.R`: compute the labour embodied in trade
- `4_figures.R`: compile data for the figures of the article

### Reproduction of the results

#### Software requirements

You need [R](https://cran.r-project.org/) and [Python](https://www.python.org) to execute the source code.  
We recommend the use of the [RStudio Integrated Development Environment](https://posit.co/products/open-source/rstudio/).

#### Information on external data

The external data is stored as .ods files in the following folder: `./data/external/`.  
Each file contains two sheet: "data" and "metadata" (description of the data, including the source). 

⚠ The GLORIA dataset used in the pipeline is not stored on this repository and must be downloaded separately (see instructions below).

**General information about the GLORIA dataset**

- Source: 
  - Lenzen et al., 2022. Implementing the material footprint to measure progress towards Sustainable Development Goals 8 and 12. Nat Sustain 5, 157–166.
  - Lenzen et al., 2017. The Global MRIO Lab – Charting the World Economy. Econ. Systems Research 29 (2): 158–86.   
- Release: 059a
- Link: https://ielab.info/ (creation of a free account is required)
- Files downloaded:
    - `GLORIA_MRIOs_59_1990.zip`
    - ... (all years from 1990 to 2018)
    - `GLORIA_MRIOs_59_2018.zip`
    - `GLORIA_SatelliteAccounts_059_1995.zip`
    - ... (all years from 1995 to 2018)
    - `GLORIA_SatelliteAccounts_059_2018.zip`
    - `GLORIA_ReadMe_059a.xlsx`

#### Instructions

1. Download this repository and extract it in a working folder
2. Download the GLORIA dataset (see "General information about the GLORIA dataset")
3. Extract the .zip *files* as *folders*, and group them together in a folder named "raw". 
4. Place the `raw/` folder in a working folder of your choice (for example: `./data/external/gloria/`)
4. Open the main `.Rproj` file, then the `.targets.R` file and: 
  - *Section "Install packages"*: follow instructions to install potentially missing packages
  - *Section "Parameters"*: update `path_gloria` with the path of the working folder where you placed the `raw/` folder containing the GLORIA dataset
5. Execute the following commands from the console:
  - Load the *targets* library: `library(targets)`
  - Run the pipeline: `tar.make()`
